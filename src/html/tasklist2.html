จัดการงานและ import ข้อมูลจาก Excel อย่างมีประสิทธิภาพ

📋 รูปแบบไฟล์ Excel ที่รองรับ (Sheet เดียว)

Sheet "Tasks" - ใส่ทั้งงานหลักและงานย่อยใน Sheet เดียวกัน:

คอลัมน์หลัก:
  • • task_id - รหัสงาน (เลขเฉพาะ)
  • • title - ชื่องาน/งานย่อย
  • • description - รายละเอียด (ไม่บังคับ)
  • • parent_task_id - รหัสงานหลัก (สำหรับงานย่อย)
คอลัมน์เพิ่มเติม:
  • • priority - ความสำคัญ (high/medium/low)
  • • status - สถานะ (todo/in-progress/completed)
  • • deadline - กำหนดส่ง (YYYY-MM-DD)
  • • completed - สำเร็จแล้ว (true/false สำหรับงานย่อย)
💡 วิธีการใช้งาน:
  • • งานหลัก: ใส่ task_id และปล่อย parent_task_id ว่าง
  • • งานย่อย: ใส่ task_id ใหม่ และระบุ parent_task_id เป็นรหัสงานหลัก
  • • งานย่อยจะใช้ completed แทน status
